# QA CHECKLIST — Before Sharing

## Visual direction

- [ ] It feels like a greeting card / art print, not a website.
- [ ] Light mode is enforced on every device.
- [ ] The visual tone is feminine, warm, contemporary, and playful without becoming childish.
- [ ] Each screen has its own composition; the 17 screens do not look like identical cards.
- [ ] Whitespace is generous and deliberate.
- [ ] Texture is subtle and does not reduce readability.
- [ ] No random gradients, generic stock photos, glassmorphism, or heavy shadows.

## Story and copy

- [ ] All 17 screens are present and in the correct order.
- [ ] Page 01 delivers the mock-serious “I'm done with you, Tamatar” bait.
- [ ] Page 02 immediately reveals the playful twist.
- [ ] Tanglish and inside-joke spellings are preserved.
- [ ] No quote is falsely attributed to Thabbu.
- [ ] The ending is affectionate and pressure-free.
- [ ] No medical, medication, or reproductive-health details appear.

## Mobile behaviour

- [ ] Tested at 360 × 800.
- [ ] Tested at 375 × 812.
- [ ] Tested at 390 × 844.
- [ ] Tested on a narrow screen with large text settings.
- [ ] Horizontal swipe feels natural and snaps cleanly.
- [ ] No accidental vertical page scroll in the normal experience.
- [ ] No copy is clipped behind browser controls or safe areas.
- [ ] Text remains readable without zooming.

## Interaction and accessibility

- [ ] Progress indicator updates correctly.
- [ ] First-screen swipe hint disappears after navigation.
- [ ] Optional reveals are discoverable and skippable.
- [ ] Keyboard left/right navigation works on desktop.
- [ ] Focus states are visible.
- [ ] Reduced-motion preferences are respected.
- [ ] No autoplay sound or forced page advance.
- [ ] No interaction is required to read essential copy.

## Technical

- [ ] No console errors.
- [ ] No TypeScript errors.
- [ ] Production build succeeds.
- [ ] No unnecessary external API requests.
- [ ] Fonts have fallbacks.
- [ ] The app runs from a fresh install using the README instructions.
